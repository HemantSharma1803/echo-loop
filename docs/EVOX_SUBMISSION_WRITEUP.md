# EVOX 1.0 — ECHO//LOOP Submission Write-up

## Page 1 — Game Concept

### ECHO//LOOP
**Tagline:** Every action leaves a trace.

**Genre:** Cinematic 2D/2.5D sci-fi time-loop puzzle adventure.

### Concept
ECHO//LOOP places the player inside the damaged AEGIS Temporal Research Facility, where time repeatedly resets but the player's previous actions survive as temporal Echoes. Each completed loop becomes a deterministic replay performed by a past version of the player. The current player must intentionally record useful behavior, then cooperate with those Echoes to activate systems, cross hazards, synchronize actions and solve increasingly complex temporal puzzles.

### Core Innovation
The player's own history is the puzzle-solving system. Instead of fighting or directing conventional NPC companions, the player creates future collaborators simply by deciding what to do in the current loop. This creates a gameplay language built around planning, timing, experimentation and temporal cause-and-effect.

### Gameplay Pillars
1. **Record** — move, interact and intentionally create a useful timeline.
2. **Reset** — time collapses and the previous timeline becomes an Echo.
3. **Cooperate** — work alongside one or more Echoes to operate the facility.
4. **Experiment** — combine Echo-only systems, timing, resonance, phase and synchronization mechanics.
5. **Discover** — uncover the facility's mystery and the recurring Unknown Echo.
6. **Master** — replay chambers, discover secrets and improve temporal efficiency.

### Signature Systems
- Deterministic Echo recording/replay
- Multi-Echo cooperation
- Pressure plates, switches, doors, hazards and moving platforms
- Player-only and Echo-only interactions
- Temporal Memory and Memory Objects
- Resonance and Temporal Stability
- Echo Synchronization
- Temporal Phase objects
- Paradox states and controlled anomalies
- Chain-reaction puzzles
- Unknown Echo narrative mystery
- Local progression, achievements, secrets and best-run traces

### Presentation
The visual direction uses a dark futuristic research facility, restrained neon emissive lighting, temporal distortion, holographic interfaces, cinematic transitions, layered particles and a premium sci-fi HUD. The presentation is designed to support the gameplay rather than replace it.

### Technical Approach
The game is a static browser application built with React, TypeScript, Vite and HTML5 Canvas. No backend, database or runtime API key is required. Local browser storage handles optional progression data. The project includes a GitHub Actions workflow for GitHub Pages deployment.
